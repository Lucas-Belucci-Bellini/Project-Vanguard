# Referências oficiais de acessibilidade — 2026-08

A consulta ao documento oficial [Web Content Accessibility Guidelines (WCAG) 2.2](https://www.w3.org/TR/WCAG22/) confirmou que a recomendação do W3C cobre conteúdo em desktop e dispositivos móveis e apresenta critérios testáveis. A mesma página lista, entre outros, **2.4.1 Bypass Blocks**, **2.4.7 Focus Visible** e **4.1.3 Status Messages**.

O projeto usa a técnica geral [G1 — link no topo para a área de conteúdo principal](https://www.w3.org/WAI/WCAG22/Techniques/general/G1) como fundamento do link **Pular para o conteúdo principal**. Para o foco visível e mensagens de status, as referências são [Understanding 2.4.7 Focus Visible](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html) e [ARIA22 — role=status](https://www.w3.org/WAI/WCAG22/Techniques/aria/ARIA22).

Essas fontes fundamentam a decisão de engenharia, mas não significam conformidade WCAG completa. A verificação de leitores de tela, contraste e uso real continua pendente em Android/iOS.
