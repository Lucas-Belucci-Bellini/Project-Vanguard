COMUNICAÇÃO RESPONSÁVEL

Socorro preparado não é resgate acionado

O Vanguard Field organiza as coordenadas para facilitar o pedido de ajuda, mas não transmite a mensagem sozinho. Posicionamento e comunicação são funções diferentes.

O que o pacote local faz

Captura de dados vitais

Reúne MGRS, latitude/longitude, precisão do fixo e horário da leitura em um formato padronizado.

Preparação da mensagem

Gera um texto claro e objetivo, pronto para ser lido em rádio ou enviado por mensagem de texto.

Compartilhamento manual

Disponibiliza os dados para a área de transferência ou para a API de compartilhamento do sistema operacional.

O que o aplicativo NÃO faz

Não envia SOS automático

A fila offline bloqueia operações de emergência. O envio depende de ação explícita e rede disponível.

Não confirma entrega

Copiar ou compartilhar os dados não garante que a mensagem foi recebida por uma equipe de resgate.

Não substitui hardware

O aplicativo não transforma o celular em rádio VHF/UHF, beacon de emergência ou mensageiro via satélite.
